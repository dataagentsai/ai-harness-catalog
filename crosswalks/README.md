# Crosswalks

Mappings out of this catalog into other people's work. Keyed by `AHC-####`.

| Target | Direction | Status |
|---|---|---|
| AI Assurance Catalog | `discharges` on each capability | in the capabilities themselves |
| Coverage: obligations with no discharging capability | derived | Phase 6 |
| OpenTelemetry GenAI semantic conventions | L11 capabilities → span attributes | planned |

The assurance crosswalk runs **both ways**, and the reverse direction is the
useful one: a gating obligation that no capability discharges is a hole in this
catalog, not in that one.
